# Data notice

This repository contains code, configuration, an empty Excel presentation
template, and a sample research memo. It does not redistribute complete
historical datasets downloaded from FRED or other data providers.

The workflow retrieves public economic and market series from the Federal
Reserve Economic Data service. Data users remain responsible for complying
with the terms, attribution requirements, and usage policies of the original
providers.

The optional local High Yield OAS history file is not included. Place any
user-supplied extension data under `data/local/`, which is excluded from Git.
